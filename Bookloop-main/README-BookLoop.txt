BOOKLOOP — FRONT-END DEMO
========================
HOW TO RUN
1. Extract this ZIP to a normal folder.
2. Open the inner Bookloop-main folder in VS Code.
3. Open index1.html in a browser (recommended: VS Code Live Server).
4. Use Browse, Sign up, Sell a book, My shelf and Messages.

DEMO LOGIN
Email: nusrat@bookloop.demo
Password: bookloop

FUNCTIONAL FEATURES
- Local demo sign-up and login
- Browse/search/filter/sort book listings
- Create, edit, mark sold/available and delete own listings
- Book detail page and contact seller action
- Basic buyer/seller messaging
- Profile display and name editing
- Home page price calculator

IMPORTANT LIMITATION
This is a front-end prototype. Data is stored in the browser's localStorage on that device/browser.
It is NOT a live multi-user website: accounts, listings, photos and messages do not sync between
different devices or users. Passwords are not securely handled and must not be used for real accounts.
A production version needs a backend, database, authentication and image storage.
